# Afterburner

A Chrome extension that removes the 16-character limit on Basecamp boost messages.

![afterburner in action](./assets/afterburner_1.gif)

## Install

1. Clone this repo
2. Open `chrome://extensions` in Chrome
3. Enable **Developer mode** (toggle in the top right)
4. Click **Load unpacked**
5. Select the `afterburner` directory

The extension activates automatically on `*.basecamp.com` pages.

## Development
